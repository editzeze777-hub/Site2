🎬 GUIA CAPCUT

Biblioteca de efeitos para edits

Passo a passo rápido para montar shake, zoom, reverse, velocity, glow, RGB e a famosa Montagem Guerreiro no CapCut pelo celular.

SHAKEIMPACTO

💥 Shake forte

  1. Selecione o clipe e abra Animação → Combo ou use keyframes.
  2. Nos pontos de batida, alterne posição alguns pixels para os lados e para cima/baixo.
  3. Use rotação pequena, cerca de 2° a 5°, e aumente um pouco o zoom para não aparecer borda.
  4. Deixe os movimentos bem rápidos, acompanhando a batida.
🔥 Dica: combine shake + flash branco bem curto no impacto.
ZOOMGLOW

🔍 Zoom + Glow

  1. Coloque um keyframe no começo do impacto com escala normal.
  2. Avance poucos frames e aumente a escala para criar o soco visual.
  3. Adicione Efeitos → Desfoque/Glow com intensidade moderada.
  4. Volte rapidamente para a escala original.
⚡ Quanto menor o intervalo entre os keyframes, mais agressivo fica o zoom.
REVERSELOOP

🔄 Reverse de 1 segundo

  1. Corte exatamente o trecho que quer usar.
  2. Duplique o trecho.
  3. No segundo trecho, use Editar → Reverter.
  4. Junte: normal → reverso. Para um loop, repita a sequência.
🎯 Para ficar perfeito, corte em um movimento claro ou em uma batida da música.
VELOCITYAMV

⚡ Velocity / Speed Ramp

  1. Abra Velocidade → Curva → Personalizar.
  2. Deixe a entrada mais lenta, acelere no impacto e desacelere na saída.
  3. Use vários pontos para formar uma curva suave.
  4. Sincronize o pico da velocidade com a batida.
🎵 Uma música com batidas bem marcadas deixa o velocity muito mais bonito.
RGBCHROMA

🌈 RGB Split / Chroma

  1. Duplique o clipe ou use um efeito RGB do CapCut.
  2. Desloque levemente as camadas/canais para criar a separação de cores.
  3. Use o efeito apenas nos impactos para não poluir o edit.
  4. Combine com shake e blur por poucos frames.
💎 Pouca intensidade costuma parecer mais profissional que RGB exagerado.
GUERREIROMONTAGEM

⚔️ Montagem Guerreiro

  1. Separe os melhores momentos do personagem em cortes curtos.
  2. Sincronize cada corte com as batidas mais fortes.
  3. Use zoom + shake + flash + blur nos impactos.
  4. Intercale cenas rápidas com um reverse curto para dar sensação de combo.
  5. Finalize com um impacto forte, texto ou transição sincronizada.
🔥 Fórmula rápida: corte → zoom → shake → flash → reverse → próximo corte.
FLASHIMPACTO

✨ Flash branco de impacto

  1. Adicione uma imagem/fundo branco sobre o ponto da batida.
  2. Deixe o flash extremamente curto, por poucos frames.
  3. Use opacidade alta no primeiro frame e reduza rapidamente.
  4. Combine com shake para dar mais força ao impacto.
COMBOBER STYLE

🔥 Combo insano para AMV/Velocity

  1. Antes da batida: zoom leve e blur.
  2. Na batida: shake + flash + RGB.
  3. Logo depois: reverse curtinho ou desaceleração.
  4. Saída: volta para o movimento normal e prepara o próximo corte.
🚀 Não use todos os efeitos o tempo todo. Guarde os mais fortes para as batidas principais.
